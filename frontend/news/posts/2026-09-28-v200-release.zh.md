# v2.0.0 - EFTForge 步入全新时代

**发布日期：** 2026-09-28

EFTForge v2.0.0 正式发布。「逃离塔科夫」武器配置模拟的全新时代，由 Kitbash! Arcadia 驱动。

---

## Kitbash! Arcadia：3D 改装界面

![Kitbash! Arcadia](./news/images/v200/kitbashArcadia.png "Kitbash! Arcadia")

Kitbash! 最初的版本是 **Kitbash! Sirius**，也就是从 v1.6.0 起绘制 EFTForge 所有配置图片的 2D 精灵图合成器。**Kitbash! Arcadia** 是她的下一个版本：同样的图像渲染器，再加上一个直接在浏览器里运行的完整 3D 引擎。

通过左上角的 **2D / 3D** 切换按钮即可开启 3D 改装界面，你的选择会被记住：

![3D 改装界面](./news/images/v200/3dBuilder.webp "3D 改装界面")

- **在模型上直接改装。** 每个槽位都以方块形式排布在枪械周围。左键单击选择配件，右键单击移除配件。安装、移除与配件冲突都会在模型上闪烁提示，与 2D 一致。
- **两种选配件的方式。** 可以使用停靠在右侧的配件列表，也可以开启 **紧凑配件列表**，使用游戏内风格的改装下拉列表，还带有随商人等级变化的可购角标。
- **瞄具视角。** 透过配置上的每一个瞄具观察，切换瞄具（V）、切换瞄具模式（M），倍镜还可以用鼠标滚轮无极变倍。

![瞄具视角](./news/images/v200/sightPicture.webp "瞄具视角")

- **模拟瞄准。** 像游戏里一样从腰射姿态开镜，手臂耐力、过摆与武器晃动都由配置的重量和人机工效、你的力量与技能等级以及装备人机工效修正共同决定。想深入研究的话，**高级瞄准诊断** 可以查看整个瞄准模型的实时图表。

![高级瞄准诊断](./news/images/v200/advDiag.webp "高级瞄准诊断")

- **靶场。** 设置目标距离与画面比例。也可以隐藏靶场，在枪后面换上纯色背景、绿幕或蓝幕色键，或者任意自定义颜色。
- **战术装置。** 开启战术灯与激光（可见激光与红外激光），直接查看光束效果。
- **枪口烟雾与火光模拟。** 按武器射速单发、连发或按住持续射击，比较每个枪口装置产生的烟雾与火光：单发烟雾量、瞄准点附近被遮挡的视野，以及火焰和火花的位置。

![枪口烟雾与火光模拟](./news/images/v200/smokeFlashSim.webp "枪口烟雾与火光模拟")

- **弹药装填。** 开启 **装满弹匣** 时，弹匣与枪膛会装入你所选的弹药。

**注意事项：**

- 3D 改装界面会使用你的显卡进行实时渲染。**不建议** 在「逃离塔科夫」运行时使用，否则可能影响你的游戏性能。随时可以通过左上角的 **2D / 3D** 切换按钮在 3D 与传统 2D 工作台之间切换，切换到 2D 后 3D 视图会被完全关闭，不会在后台占用任何性能。
- 移动端继续使用 2D 工作台。
- 桌面版中，3D 改装界面需要在 **连接 EFTForge.com** 模式下使用。**本地模式** 保持 2D，任何数据都不会离开你的电脑。

### 3D 里有东西看起来不对？

和 Kitbash! Sirius 一样：配件位置不对、模型缺失、瞄具对不准，任何问题都可以通过 [B站](https://space.bilibili.com/650421245) 私信或 [GitHub Issues](https://github.com/SouthHorizons76/EFTForge/issues) 反馈给我。附上问题截图会很有帮助！

## 真实人机 (TrueErgo) 取代 EvoErgo

EvoErgo 用一条拟合曲线来估算过摆。**真实人机 (TrueErgo)** 采用的则是游戏实际使用的规则：当 重量 x（1 - 人机工效 / 100）超过 3 kg 时，开镜就会过摆。

- **真实人机Delta（TED）** 表示你的配置在过摆之前还能损失多少人机工效，单位就是普通的人机点数。大于 0 就没问题，小于 0 就会过摆。
- **过摆** 现在是精确判断。它和新增的 **过摆强度** 百分比显示在同一行：有效重量 3 kg 以下为 0%，有效重量达到 7 kg 及以上为 100%，所以你会看到类似「是 - 45%」这样的显示。
- **手臂耐力** 现在采用游戏自身的消耗公式，包括每级力量减少 0.4% 的消耗。
- **MOA** 现在会计入所装弹药的精准度修正。
- 优化器中的 **使用 EvoErgo** 现在变成了 **使用真实人机**，最大 MOA 限制也会计入所装弹药。你保存的优化器设置会自动保留。
- 社区配置卡片会显示 TED，并且可以按 **最高TED** 排序。本次更新之前发布的配置会根据其保存的人机工效与重量自动计算。

真实人机衍生自 **SpaceMonkey37** 提出的 EvoErgo 概念。再次感谢 SpaceMonkey37 开创了把人机工效与重量结合起来评估的思路！

## 优化器：包含无价格配件

优化器的市场设置中新增了 **包含无价格配件** 开关，默认开启。在你当前的购买权限下无法从商人或跳蚤市场买到的配件（仅竞技场、仅以物易物、跳蚤禁售）现在也可以被选进配置中。

由于它们的价格未知，它们永远不会被当作免费：属性相同时总是优先选择有价格的配件，设置预算上限时会排除它们，价格相关的曲线上也不会出现它们。它们在配件清单中显示为「-」，也不会计入总价。

## 开火声音属性

枪口装置、消音器和少数枪管现在会在配件列表和优化器的配件清单中以可排序列显示 **开火声音** 属性，高级属性面板也会汇总整套配置的数值。

提醒一下：游戏其实从来不会读取这个数值。真正影响枪声和 AI 听到你的距离的，只有是否装了消音器。哈哈

## 数据变动追踪：完整历史

数据变动追踪默认仍然显示最近 7 天，但搜索框旁新增的日期选择器会列出所有发生过变动的同步日，历史记录有多久，你就能往回看多久。

## 本次更新也包含：

- 网站上所有的滚动条都换成了与整体界面风格一致的纤细自定义滚动条。鼠标悬停时淡入，拖动时变为金色。触屏设备保留原生滚动条。
- 点阵背景跟随鼠标移动更加流畅，绘制开销也更低。
- 右侧边缘的优化器标签不会再对首次访问的用户自动弹出。
- 网页版的「关于」窗口新增了 Windows 桌面版的下载链接，可以从 GitHub Releases 或 Gitee 镜像下载。
- 修复了切换语言时会关闭当前配置标签页的问题。现在标签页会保持打开，名称与撤销记录也都会保留。
